# 📊 Superstore Sales & Profit Analysis (Tableau Dashboard)

## 📌 نظرة عامة على المشروع (Project Overview)
تحليل تفاعلي لبيانات مبيعات وأرباح متجر **Sample Superstore** في الولايات المتحدة، بهدف استكشاف أداء الأقسام الرئيسية، تحديد المنتجات التي تحقق خسائر بسبب الخصومات المرتفعة، وتحليل التوزيع الجغرافي للمبيعات عبر الولايات.

## 💡 أهم الاستنتاجات (Key Insights)
* **تأثير الخصومات على الربحية:** بعض المنتجات الفرعية مثل الطاولات (`Tables`) تحقق مبيعات مرتفعة لكنها تسجل صافي خسارة بسبب الخصومات العالية.
* **أداء الفئات:** قسم التكنولوجيا (`Technology`) يحقق أعلى هامش ربح مقارنة بالأثاث والمستلزمات المكتبية.
* **التوزيع الجغرافي:** تتركز أعلى المبيعات في ولايات محددة مثل كاليفورنيا ونيويورك، مما يوضح فرص التوسع في الولايات الأقل مبيعاً.

---

## 🛠️ الأدوات المستخدمة (Tools & Skills)
* **Tableau Desktop:** بناء الرسومات البيانية، الخرائط الجغرافية، والفلاتر التفاعلية.
* **Data Cleaning:** تصفية البيانات واستبعاد السجلات المكررة (`Is Duplicate = 0`).
